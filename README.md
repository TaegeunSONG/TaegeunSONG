PI of the [AI-integrated Physics Lab](https://sites.google.com/view/tslab-aip/home)

- Biophysical modeling (glucose homeostasis, cell migration, hearing mechanism)
- Hybrid quantum devices (NEMS, graphene p–n junctions, flying qubits)
